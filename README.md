# Atlas de IA

Web de estudio de inteligencia artificial: 138 conceptos, desde el álgebra lineal hasta los LLM, cada uno en una ficha con intuición, explicación, fórmulas, un interactivo, código, errores típicos y autoevaluación. Se navega por un mapa de requisitos y guarda tu progreso en el navegador.

- Web: carpeta `docs/` (GitHub Pages) o abre `docs/index.html` directamente.
- Contenido: `fichas/*.md`. Estructura y fuentes: `inventario.json`.
- Cómo se construye: `PASOS.md`. Instrucciones para Claude: `CLAUDE.md`.
